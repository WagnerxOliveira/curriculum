## 📖 Sobre o Projeto

Este projeto consiste na digitalização do meu Currículo Profissional (CV) em formato de página web. O objetivo principal é demonstrar de forma prática e interativa minhas habilidades iniciais com o desenvolvimento Front-end, além de facilitar o acesso de recrutadores às minhas informações acadêmicas, experiências e formas de contato.

O layout foi pensado para ser limpo (Clean Design), utilizando uma paleta de cores agradável e tipografia moderna para garantir a melhor experiência de leitura.

---

## ✨ Funcionalidades e Destaques

- **HTML Semântico:** Estruturação correta das tags para melhor acessibilidade e SEO.
- **CSS Moderno:** Utilização de `CSS Grid` e `Flexbox` para o layout e posicionamento dos elementos.
- **Tipografia:** Integração com o Google Fonts (famílias *Hubballi* e *Montserrat*).
- **Ícones:** Utilização da biblioteca *FontAwesome* para uma interface mais rica visualmente.
- **Hospedagem:** Deploy automatizado e rápido através da plataforma Vercel.

---

## 🛠️ Tecnologias Utilizadas

O projeto foi construído utilizando as seguintes tecnologias:

*   **[HTML5](https://developer.mozilla.org/pt-BR/docs/Web/HTML):** Linguagem de marcação utilizada para a construção das páginas.
*   **[CSS3](https://developer.mozilla.org/pt-BR/docs/Web/CSS):** Linguagem de folhas de estilo utilizada para a formatação e layout.
*   **[FontAwesome](https://fontawesome.com/):** Biblioteca de ícones.
*   **[Google Fonts](https://fonts.google.com/):** Biblioteca de fontes.
